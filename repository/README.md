# Platform Repository Alanı

Bu klasör platform katalog/repository sözleşmeleri için ayrılmıştır; bağımsız ürün Git depolarını içermez.

- `apps/`: gelecekte yayımlanmış uygulama kayıtları veya kontrollü katalog girdileri.
- `schemas/`: repository ve katalog şemaları.

`apps/products.json`, bağımsız ZUI ürün depoları için ilk source-free internal registry'dir ve `schemas/product-registry.schema.json` sözleşmesini kullanır. Yerel ürün yolları, gizli değerler, TV anahtarları, kullanıcı IPTV bilgileri ve yayımlanmamış artifact'ler bu alana yazılmaz.
