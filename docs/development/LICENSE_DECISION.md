# License Decision

Date: 2026-10-02  
Decision: MIT License for original ZUI webOS Platform code.

The platform foundation is newly authored management and developer tooling. It does not copy or incorporate ZUI YouTube source, so the YouTube repository's GPL license is not inherited merely because the platform records its public repository and application IDs.

ZUI IPTV Player and ZUI YouTube for webOS remain independent repositories under their existing licenses. Product registry metadata is factual linkage, not source-code incorporation or relicensing.

MIT was selected to keep original platform libraries and tooling permissively reusable while retaining copyright and warranty notices.
